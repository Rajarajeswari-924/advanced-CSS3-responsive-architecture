This project is a simple and modern responsive webpage layout created using HTML, CSS Grid, Flexbox, media queries, and CSS variables.

CSS Grid is used to build the overall page structure, such as the sidebar and main content area. It helps organize the page in rows and columns, making the layout clean and flexible.

Flexbox is used inside smaller sections like the navigation bar and card container. It makes alignment and spacing easier, especially for arranging items horizontally and wrapping them automatically on smaller screens.

The design follows a mobile-first approach, meaning the layout is first designed for mobile devices and then adjusted for larger screens using responsive media queries. This ensures the webpage looks good on phones, tablets, and desktops.

CSS variables are used to create a dynamic light and dark mode theme. Instead of rewriting multiple styles, colors are stored in variables and changed efficiently by toggling a single class. When the user clicks the “Toggle Mode” button, the website instantly switches between light mode and dark mode.
